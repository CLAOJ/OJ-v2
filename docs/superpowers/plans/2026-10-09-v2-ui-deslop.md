# v2 UI De-slop Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Strip the generic "AI-generated" decoration from `claoj-web` so v2 reads as a dense, utilitarian online judge like v1 — styling only, every page.

**Architecture:** A committed regression guard (`npm run ui:check`) defines the banned patterns and is each task's red/green test. A throwaway, pre-tested codemod applies the mechanical class swaps; each task then does a short hand pass for context-dependent rules (gradients, heavy shadows, decorative icon colours, spacing, weights on non-heading text) and verifies with lint/test/build plus Playwright screenshots. Pages are swept in traffic order, one commit per area.

**Tech Stack:** Next.js 16.1.6 · React 19.2.3 · Tailwind CSS v4 (`@theme` tokens in `globals.css`) · class-variance-authority · framer-motion · Jest 30 + React Testing Library · Node 24 (scripts) · Playwright (throwaway, screenshots only).

**Spec:** `docs/superpowers/specs/2026-10-09-v2-ui-deslop-design.md` — binding; this plan argues from it.

### Hand rules (applied in every sweep task's hand pass)

- **H1 Heavy shadow.** `shadow-md/lg/xl/2xl` on static, in-flow surfaces (cards, tables, auth cards, banners) → remove; the border carries it. Keep them on floating layers only: dialogs, popovers, dropdown menus, toasts, the mobile drawer, the back-to-top button. `hover:shadow-*` → remove. `shadow-sm` stays.
- **H2 Gradients.** Initials/logo tiles `bg-gradient-to-br from-primary/20 to-primary/5` → `bg-muted`. Hover overlays (`absolute inset-0 bg-gradient-… opacity-0 group-hover:opacity-100`) → delete the element. Decorative hairlines (`h-px bg-gradient-to-r from-transparent via-…`) → delete the element. Coloured gradient buttons/menu items (amber→orange admin entry, indigo→purple avatar) → the same classes as their plain siblings (e.g. `bg-muted text-foreground hover:bg-muted/70`), icon `text-muted-foreground`. Dark hero banners (`from-slate-900 via-slate-950`) → `bg-card border`.
- **H3 Weights.** `font-bold` on body text, labels, table cells, buttons → `font-medium`; on h1–h3 → `font-semibold`. Review every `font-medium`/`font-semibold` the codemod produced from `font-black`: h1–h3 are `font-semibold` at any size, and so are headline numbers (`text-lg` and up); everything else is `font-medium`.
- **H4 Decorative icon colour.** An icon/accent colour that encodes nothing (e.g. `text-amber-500` beside "Points", `text-purple-500` on a Clock in problem limits, `text-orange-500` on an Rss icon) → `text-muted-foreground`. Test: if removing the colour loses information (verdict, rating, status, error), it is on the keep list — leave it.
- **H5 Spacing one step down** on cards/sections: `p-8`/`p-10` → `p-4` (auth cards `p-5`), `px-8` on buttons → `px-4`, `gap-8`/`gap-10` → `gap-4`, `space-y-8`/`space-y-10` → `space-y-4`, `py-12+` section padding → `py-6`, `h-12`/`h-14` hero buttons → `h-9`/`h-10`.
- **H6 Pills and leftovers.** `rounded-full` on buttons, tabs, chips → `rounded`; keep `rounded-full` on avatars, status dots, spinners, the back-to-top button. Remove `transition-transform` / `duration-NNN` left on elements that no longer transform. Remove `uppercase` on word labels and section headings; keep it on codes (AC, WA, problem codes, keys).
- **H7 Glass.** Any surviving `bg-*/80`-style translucent sticky bar → solid `bg-card`. Sticky tab bars must keep `sticky top-4 z-10 overflow-x-auto`.

## Review Focus

1. **A semantic colour stripped by the hand pass** (verdict, rating, contest status, difficulty) — a person scanning submissions must still see AC green / WA red / TLE amber. Pinned by the keep-list diff check in Tasks 3, 4 and 8.
2. **A status dot or avatar losing its circle** when `rounded-full` is changed under H6 — online/live dots must stay round. Pinned by the `rounded-full` diff review in Tasks 3–8.
3. **Sticky tab bars on profile/organization pages at 390px** — after the glass is removed they must stay sticky and scroll horizontally, not wrap or clip. Pinned in Task 5.
4. **Light-theme label contrast** — labels become `text-xs text-muted-foreground`; on `bg-muted` surfaces in the light theme they must stay readable (#546e7a on #eceff1 ≈ 5:1). Pinned by the light-theme screenshot review in every sweep task.
5. **Pages that cannot be checked visually** (admin, settings, notifications need login; dynamic pages need data) — the report must name them as unverified rather than claim a visual pass. Pinned in Tasks 7 and 8.

`scripts/check-ui-slop.mjs`:

```js
import { readFileSync, readdirSync, statSync } from 'node:fs';
import { join, relative } from 'node:path';

// Decorative patterns banned by docs/superpowers/specs/2026-10-09-v2-ui-deslop-design.md.
// A line containing `ui-check-allow` is skipped.
const RULES = [
    ['font-black', /\bfont-black\b/],
    ['tiny-text', /\btext-\[(8|9|10)px\]/],
    ['wide-tracking', /\btracking-(widest|\[0\.\d+em\])/],
    ['big-radius', /\brounded-(2xl|3xl|\[[\d.]+rem\])/],
    ['hover-motion', /\b(hover|active):-?(scale|translate)-/],
    ['gradient', /\bbg-(gradient|linear|radial|conic)-/],
    ['blur', /\bbackdrop-blur/],
    ['heavy-shadow', /\bshadow-(2xl|[a-z]+(-\d+)?\/\d+)/],
    ['page-fade', /\banimate-in\b/],
];

const walk = (p) => statSync(p).isDirectory()
    ? readdirSync(p).flatMap((f) => walk(join(p, f)))
    : /\.(tsx|ts)$/.test(p) ? [p] : [];

const targets = process.argv.slice(2);
const files = (targets.length ? targets : ['src']).flatMap(walk);
const counts = {};
let hits = 0;

for (const file of files) {
    readFileSync(file, 'utf8').split('\n').forEach((line, i) => {
        if (line.includes('ui-check-allow')) return;
        for (const [name, re] of RULES) {
            if (!re.test(line)) continue;
            console.error(`${relative('.', file)}:${i + 1}  [${name}]  ${line.trim().slice(0, 120)}`);
            counts[name] = (counts[name] || 0) + 1;
            hits++;
        }
    });
}

if (hits) {
    console.error(`\nui:check FAILED: ${hits} hits in ${files.length} files`, counts);
    process.exit(1);
}
console.log(`ui:check OK: ${files.length} files clean.`);
```

- [ ] **Step 6: Write the codemod**

`../.superpowers/deslop/codemod.mjs`:

```js
// Mechanical de-slop pass (spec: docs/superpowers/specs/2026-10-09-v2-ui-deslop-design.md).
// Usage: node codemod.mjs <file-or-dir>...   Rewrites in place; review every changed line.
import { readFileSync, writeFileSync, readdirSync, statSync } from 'node:fs';
import { join } from 'node:path';

// A whole Tailwind token, with any variant prefixes (md:, dark:, group-hover:, ...).
const tok = (body) => new RegExp(`(^|[\\s"'\`])((?:[a-z0-9-]+:)*)${body}(?=[\\s"'\`]|$)`, 'g');
const drop = (body) => [tok(body), '$1'];
const swap = (body, to) => [tok(body), `$1$2${to}`];

const ALWAYS = [
    drop('(?:group-hover|group-active|hover|active):-?(?:scale|translate)-[^\\s"\'`]+'),
    drop('backdrop-blur(?:-[a-z0-9]+)?'),
    swap('bg-card\\/80', 'bg-card'),
    drop('shadow-[a-z]+(?:-\\d+)?\\/\\d+'),
    swap('rounded-(?:2xl|3xl|\\[[\\d.]+rem\\])', 'rounded-md'),
];
// Tiny uppercase letter-spaced labels -> plain text-xs.
const LABEL = /text-\[(?:8|9|10)px\]|tracking-(?:widest|\[0\.\d+em\])/;
const LABEL_FIX = [
    swap('text-\\[(?:8|9|10)px\\]', 'text-xs'),
    drop('tracking-(?:widest|wider|\\[0\\.\\d+em\\])'),
    drop('uppercase'),
];
// Page-level entrance animation.
const FADE = /\banimate-in\b/;
const FADE_FIX = [drop('(?:animate-in|fade-in|zoom-in-\\d+|slide-in-from-[a-z]+(?:-\\d+)?|duration-\\d+)')];
const HEADING = /<h[1-3]\b|\btext-(?:lg|xl|[2-9]xl)\b/;

const apply = (line, rules) => rules.reduce((l, [re, to]) => l.replace(re, to), line);

export function fixLine(line) {
    if (line.includes('ui-check-allow')) return line;
    let out = apply(line, ALWAYS);
    if (LABEL.test(out)) out = apply(out, LABEL_FIX);
    if (FADE.test(out)) out = apply(out, FADE_FIX);
    out = apply(out, [swap('font-black', HEADING.test(out) ? 'font-semibold' : 'font-medium')]);
    if (out === line) return line;
    // Collapse double spaces left by dropped tokens, only on lines we changed.
    return out.replace(/(\S) {2,}(?=\S)/g, '$1 ');
}

const walk = (p) => statSync(p).isDirectory()
    ? readdirSync(p).flatMap((f) => walk(join(p, f)))
    : /\.tsx?$/.test(p) ? [p] : [];

if (process.argv[1] && import.meta.url.endsWith(process.argv[1].split(/[\\/]/).pop())) {
    let changed = 0;
    for (const file of process.argv.slice(2).flatMap(walk)) {
        const src = readFileSync(file, 'utf8');
        const out = src.split('\n').map(fixLine).join('\n');
        if (out !== src) { writeFileSync(file, out); changed++; console.log('rewrote', file); }
    }
    console.log(`${changed} files rewritten`);
}
```

```js
// Usage: node shoot.cjs <outDir> <path | first:<listPath>:<hrefPart>>...
// BASE_URL defaults to http://localhost:3100. Captures light + dark at 1440 and 390 wide.
const { chromium } = require('playwright');
const fs = require('node:fs');

const base = process.env.BASE_URL || 'http://localhost:3100';
const [out, ...targets] = process.argv.slice(2);
fs.mkdirSync(out, { recursive: true });

(async () => {
    const browser = await chromium.launch();
    for (const colorScheme of ['light', 'dark']) {
        for (const width of [1440, 390]) {
            const ctx = await browser.newContext({ colorScheme, viewport: { width, height: 900 } });
            const page = await ctx.newPage();
            for (const target of targets) {
                let path = target;
                if (target.startsWith('first:')) {
                    const [, list, part] = target.split(':');
                    await page.goto(base + list, { waitUntil: 'networkidle', timeout: 30000 }).catch(() => {});
                    path = await page.$$eval('a[href]', (as, p) => as.map((a) => new URL(a.href).pathname).find((x) => x.includes(p)), part);
                    if (!path) { console.warn(`SKIP ${target}: no link containing ${part}`); continue; }
                }
                await page.goto(base + path, { waitUntil: 'networkidle', timeout: 30000 })
                    .catch((e) => console.warn(`WARN ${path}: ${e.message.split('\n')[0]}`));
                const slug = target.replace(/^first:/, '').replace(/[^a-z0-9]+/gi, '_').replace(/^_|_$/g, '') || 'home';
                await page.screenshot({ path: `${out}/${slug}-${colorScheme}-${width}.png`, fullPage: true });
                console.log(`${slug} [${colorScheme} ${width}] -> ${page.url()}`);
            }
            await ctx.close();
        }
    }
    await browser.close();
})();
```

The theme follows `colorScheme` because the app uses `defaultTheme="system"` (next-themes, class strategy). Routes have no locale prefix (`localePrefix: 'never'`).
